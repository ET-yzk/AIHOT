
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：机构名 / 标准号或法规文号 / 车型名 / 公司名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是标准号 / 文号 / 阶段代号 / 没信息量的 teaser（如 "GB 44496—2024"、"No.013628"、"Phase 2"、"重磅发布"）时，结合【来源】和正文把主体补进标题。例：原标题 "GB 44496—2024" + 来源 "市场监管总局／国标委：标准公告" → "GB 44496—2024《汽车软件升级通用技术要求》发布"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体标准号或文号时，用上位词（如"一项整车安全类强制性国家标准"）兜底，绝不凭"行业常识"编一个具体的标准号 / 文号 / 日期 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一项已经存在的标准、那份已经发布的法规或一个新的测评结果，就改写成“发布 / 实施 / 生效 / 批准 / 公开征求意见”。只有原标题明确宣布了其中某个动作，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的机构、标准、车型或公司名。
   例：原标题 "How Euro NCAP's new protocol tests pedestrian protection" → "Euro NCAP 新规程如何测试行人保护"，不能写成 "Euro NCAP 发布新规程"。
   例：原标题 "How to put driver monitoring into a low-cost ECU" + 来源和正文明确是博世 → "博世如何把驾驶员监测装进低成本 ECU"，不能只写成缺主体的 "如何把驾驶员监测装进低成本 ECU"。
