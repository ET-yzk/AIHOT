## 1. 目标

同事用飞书账号登录本站，在 `/subscriptions` 选择收日报、周报或月报，也可以只看自己关心的分类或主题；出刊后由 worker 把飞书卡片发到本人单聊。它与现有 RegPilot/hermes 推送并行，不修改后者的配置；验证通过后可以只保留一边。

不做：收藏上云、飞书回复退订、管理员订阅后台、一人多条订阅、实时精选推送、企微/邮件。

## 3. 数据表

| 表 | 说明 |
|---|---|
| `reader_users` | 读者：`feishu_union_id`、`feishu_open_id`、`email`、姓名、头像；至少一个标识 |
| `reader_sessions` | 会话：token 的 sha256、CSRF、`auth_binding`（绑定登录应用与读者）、30 天过期 |
| `reader_subscriptions` | 一人一行：总开关、日报/周报/月报、范围（全部/分类/主题）、所选分类与主题 |
| `reader_deliveries` | 推送账本：`UNIQUE(user_id, kind, report_key)`；状态 pending/sending/sent/failed/skipped/unknown |

不建收藏表；收藏仍只在本机。过期会话和 90 天前的推送记录每天清理；删除读者级联删除以上数据。

## 4. 登录与会话

- 复用后台飞书登录应用（`FEISHU_LOGIN_APP_ID/SECRET`）；回调 `<SITE_URL>/api/subscriptions/auth/callback`，需在飞书开放平台登记。
- state 用 `SESSION_SECRET` HMAC 签名，10 分钟过期；`returnTo` 只接受 `/subscriptions` 内路径。
- 登录后按 `union_id`、再按邮箱 upsert；会话 cookie `aihot_reader`（HttpOnly、SameSite=Lax、HTTPS 时 Secure、30 天）。
- `auth_binding = HMAC(SESSION_SECRET, ["reader-session-v1", 登录应用 ID, 读者 id])`；换应用 ID 或轮换 `SESSION_SECRET` 使旧会话失效。
- 写操作必须带 `x-csrf-token`；登录、测试消息、收藏推荐做内存限流。
- 权限边界是飞书应用的可用范围，不另设读者名单；后台管理员名单与读者无关。

## 5. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/subscriptions/options` | 公开：分类、主题、分组、`loginConfigured` |
| GET | `/api/subscriptions/auth/login` | 跳飞书授权页 |
| GET | `/api/subscriptions/auth/callback` | 校验 state，建会话，跳回 |
| POST | `/api/subscriptions/auth/logout` | 会话+CSRF：退出 |
| GET | `/api/subscriptions/me` | 会话：用户、订阅、最近 10 条推送、CSRF |
| PUT | `/api/subscriptions` | 会话+CSRF：保存设置 |
| POST | `/api/subscriptions/test` | 会话+CSRF：发测试卡片 |
| DELETE | `/api/subscriptions/me` | 会话+CSRF：删除本人资料 |
| POST | `/api/subscriptions/suggest` | 公开、限流：按收藏条目编号统计分类/主题，不保存 |

这些是本站自用接口，不属于公开 v1；公开页面、`/api/v1`、RSS、MCP、站点地图不变。

## 6. 推送

- 定时 `subscriptions.deliver` 每 5 分钟；`FEISHU_READER_PUSH_ENABLED=true` 才注册。
- 每种报取最新一期；新鲜度日报 2 天、周报 9 天、月报 32 天；只推订阅创建之后生成的期，不回填。
- 每个订阅建 `reader_deliveries` 行（`ON CONFLICT DO NOTHING`），同事务入队 `subscriptions.deliver`（batchSize 1，重试 3 次）。
- 发送前用 `itemFacets()` 过滤撤回/无页面条目；`all` 推整期（安静期也推一句说明），分类/主题订阅只推匹配条目，没有匹配记 `skipped` 不发。
- 卡片：标题 + 导语/匹配说明 + 最多 5 条链接 + 「阅读整期」「订阅管理」按钮 + 脚注；文字做 markdown 转义。
- 成功 `sent`；超时/连接中断 `unknown`（不自动重试）；飞书业务错误 `failed` 并交给队列重试。
- 告警：开关开着但消息应用没配；24 小时 `sent=0` 且 `failed+unknown>=3`。后台「运行」页可看每次扫描的 `users/created/recovered`。

## 7. 收藏推荐

- 收藏条目新增 `category`/`tags`（旧数据补 `null`/`[]`），收藏按钮写入当前条目的值。
- 订阅页只在用户点按钮时读本机收藏，POST 条目编号；服务器只做当场统计，不保存编号，也不记请求体。
- 推荐返回分类/主题计数，页面可一键采用，用户仍可手动改。

## 10. 已知边界

- 会话与限流在单个 api 进程内；多 api 进程需要共享限流（当前部署单进程）。
- 读者资料保留到用户自己删除；推送记录 90 天，会话 30 天。
- 飞书超时无法确认是否送达，记为 `unknown`，不自动重发。
- 收藏仍不跨设备；订阅设置跨设备。
