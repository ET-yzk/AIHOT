## 4. 应用启动验证

用恢复库启动 API（`API_PORT=3101`）：

```json
HTTP 200 {"ok":true,"db":"ok","ms":2,"release":"dev"}
```

结论：**恢复路径成立**。重建时按 `RESTORE.md` 执行：
