# C-NCAP 信源更新（2026-11-16）

## 结论

- 旧 JSON 接口 `/api/getPingjiaList`、`/api/getNoticeList` 已全部 404；站点改为 Next.js。
- 新站只有**一个** `/news` 列表；`?type=notice&columnId=<id>` 过滤无效（五个栏目页返回同一批 10 条）。
- 评价结果页（`/cncap` 等）没有可解析的发布日期，只有车型年份，因此 4 个评价源无法继续用日期入库。

## 变更

新增一个 `web_list` 源（后台创建，已审计）：

```json
{
  "id": "web-cncap-news",
  "name": "C-NCAP 新闻",
  "kind": "web_list",
  "tier": "T1",
  "participation_mode": "editorial",
  "interval_minutes": 120,
  "tags": ["法规", "测评"],
  "config": {
    "url": "https://www.c-ncap.org.cn/news",
    "parseMode": "html",
    "itemSelector": "a.news-card",
    "linkSelector": "a.news-card",
    "titleSelector": "h2.news-card__title",
    "publishedAtSelector": "time.news-card__date",
    "allowUrlPrefixes": ["https://www.c-ncap.org.cn/", "https://mp.weixin.qq.com/"],
    "sortByPublishedAt": true,
    "_aihot": { "initialBackfillLimit": 20 }
  }
}
```

停用 9 个旧源（`enabled=false`、`health=paused`，原 `config` 保持不动）：

`json-cncap-pingjia`、`json-cncap-ccrt`、`json-cncap-cgcaps`、`json-cncap-cicaps`、`json-cncap-notice-gjjl`、`json-cncap-notice-jgfb`、`json-cncap-notice-tg`、`json-cncap-notice-tz`、`json-cncap-notice-zydt`。

## 验证

- 预览（后台 `POST /api/admin/sources/preview`）：第 1 页 10 条，日期 `2026-10-16 ~ 2026-10-27`（北京时间）；第 2 页已是 9 月，不在缺口内。
- 首次导入：`found=10 / created=10`，落库日期 `2026-09-29 ~ 2026-10-27`，源 `health=ok`。
- 这 10 条覆盖了 10-15 ~ 10-27 的缺口尾段；10-27 之后新站本身没有更新。

## 回滚

```sql
-- 停用新源
UPDATE sources SET enabled = false, health = 'paused', next_fetch_at = now(), updated_at = now() WHERE id = 'web-cncap-news';
-- 重新启用旧源（config 未动，只恢复 enabled/health）
UPDATE sources SET enabled = true, health = 'unknown', next_fetch_at = now(), updated_at = now() WHERE id LIKE 'json-cncap-%';
```

评价结果 4 个源在新站找不到发布日期，恢复后也会持续 404；重新启用只用于回滚到旧接口可用时。
