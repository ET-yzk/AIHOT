## 2. 待接入（4 个）

### 2.1 工信部-全站新闻 5 栏目（迁移指南 #3）

- **级别**：T1
- **现状**：regpilot 走 RSSHub（`rss` kind），2.1 万条，量大
- **AIHOT 接入方式**：`rss` + `ingestNoiseFilter.keepIfMatches` 噪声过滤
- **难点**：量大（21,176 条），必须配 `allowUrlPrefixes` 收窄到 `zwgk/zcwj`、`xwfb` 等栏目路径；`interval_minutes` 建议 120
- **与 json-miit-zcwj 的关系**：json-miit-zcwj 已覆盖"政策文件"搜索，全站新闻是补充，覆盖更多栏目（新闻发布、政策解读等）
- **优先级**：中。json-miit-zcwj 已覆盖核心政策文件，全站新闻是锦上添花
- **配置草案**：
  ```jsonc
  {
    "id": "rss-miit-quanzhan",
    "name": "工信部 · 全站新闻",
    "kind": "rss",
    "config": {
      "feedUrl": "https://rss-hub-kappa-ebon.vercel.app/gov/miit/all",
      "ingestNoiseFilter": {
        "keepIfMatches": ["汽车","智能网联","车辆","驾驶","自动驾驶","辅助驾驶","装备","新能源","标准","公告","认证","安全要求"]
      },
      "allowUrlPrefixes": ["/zwgk/zcwj/", "/xwfb/"],
      "_aihot": { "initialBackfillLimit": 30 }
    },
    "tier": "T1",
    "first_party": true,
    "participation_mode": "editorial",
    "interval_minutes": 120
  }
  ```
- **状态**：待实测 RSSHub 端点可用性

### 2.2 机器之心 MCP RSS（迁移指南 #5）

- **级别**：T3（仅线索，不参与评分）
- **现状**：regpilot 走 RSS，60min 限流 1 次
- **AIHOT 接入方式**：`rss` + `interval_minutes: 60` + `participation_mode: "hot_signal"`
- **难点**：URL 带 token（`https://mcp.applications.jiqizhixin.com/rss?token=<token>`），需确认 token 有效性
- **优先级**：低。T3 源仅作事件热度证据
- **配置草案**：
  ```jsonc
  {
    "id": "rss-jiqizhixin",
    "name": "机器之心",
    "kind": "rss",
    "config": {
      "feedUrl": "https://mcp.applications.jiqizhixin.com/rss?token=<TOKEN>",
      "_aihot": { "initialBackfillLimit": 10 }
    },
    "tier": "T2",
    "first_party": false,
    "participation_mode": "hot_signal",
    "interval_minutes": 60
  }
  ```
- **状态**：待确认 token、待实测

## 5. 与迁移指南的差异说明

实际实现比迁移指南做得更好：

- **工信部政策文件**：迁移指南建议 RSSHub → 实际用原生 JSON API（json_list），不依赖第三方
- **C-NCAP 四个子栏目**：迁移指南说"必须走 external" → 实际发现 POST JSON 接口，json_list 原生支持
- **WP.29**：迁移指南建议探 UNECE 官网隐藏 RSS → 实际用 catarc.org.cn 镜像页（web_list）

这些差异说明迁移指南是保守估计，实际端点能力更强。
