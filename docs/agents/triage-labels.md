# Triage 标签

Skill 里的 triage 角色用五个固定名字，本文件把它们映射到本仓库 issue tracker 实际使用的标签字符串。

| 角色（skill 里的叫法） | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已写清，可交给离线 agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不做 |

当某个 skill 提到某个角色（例如“打上 AFK 就绪标签”）时，使用上表对应的标签字符串。

要改词表，只改“本仓库的标签”这一列。
