# 信源表页面 · 设计演示

单文件 HTML，双击打开即可，不联网、不依赖任何服务。

## 怎么看

1. 顶部黑条是**演示控制台**，不是设计的一部分：切浅色/深色、切桌面/手机 390px、模拟同步失败、重置。
2. 左侧栏「专栏 → 法规信源」高亮，就是新页面的位置（与「法规追踪」并存）。
3. 在列表里：搜索框输入 `41797` 或 `驾驶员`；点「筛选」选地区与生命周期；点「列」增减字段；点任意一行进详情。
4. 详情页点「‹ 返回法规信源」，筛选与搜索会保留（对应 FR-ST-09）。
5. 地址栏的 # 片段保存了当前筛选状态，复制到新标签页可以复现（对应 FR-ST-13）。

## 数据

10 条真实记录，取自 2026-11-17 的信源表_v2.0（共 104 条），特意包含：

- Markdown 写法的原文链接（`[中汽测评|C-NCAP 技术规程](https://…)`）
- 词表外的业务分类「底层」（截图里那个带琥珀色描边的标签）
- 缺失的发布日期（GB/T 41797-2022 之外的几条）
- 长文本的影响评估（GB 44721-2026）

## 哪些是示意，哪些已定稿

| 是示意 | 已定稿 |
|---|---|
| 分页是真实分页：104 条、15 条/页 → 7 页；顶部可切 15/30/50 | 字段分组与顺序 |
| 复制按钮不写剪贴板 | 徽章语义与配色 |
| 侧栏其他入口不跳转 | 字号、间距、圆角、发丝线 |
| 顶部「手机 390px」是**容器模拟**，不是媒体查询：它演示手机形态，不代表断点位置 | 断点已定：< 700px 换卡片（见 02 §7） |

## 2026-11-17 改版后新增的可评审项

- **分页**：默认每页 15 条，可选 15 / 30 / 50；数据是真实 104 条，所以翻页看到的是真数据。手机上只留「共 N 条 · 每页条数 · ‹ 3 / 7 ›」。
- **页脚条**：发丝线下面分两半——左边「● 信源同步于 X」，右边「数据源 飞书「信源表_v2.0」」（取 `FEISHU_SOURCE_TABLE_WEB_URL`）。圆点缓慢呼吸，绿=上次成功；鼠标悬停或 Tab 聚焦看最近 5 次与频率（每 6 小时）。同步失败时左边整行转红写「本次同步失败 · 上次成功 X」，**不再弹顶部横幅**。
- 页面里没有下划线链接（站点全局 `a{text-decoration:none}`），下拉框是自绘箭头。
- **详情页重排**：主体是摘要与影响 → 关键日期 → 适用范围 → 分类与功能 → 原文；信源与维护信息收进底部「元数据」折叠区（默认收起）。
- 点顶部「模拟同步失败」可以看红点与失败提示。
| 同步时间为固定值 | 空态、失败态、无结果态文案 |
| | 筛选与排序的交互方式 |

## 评审要回答的两个问题

1. 形态确认：桌面表格 + 手机卡片 + 独立详情页，是否就是你要的？
2. 「影响评估」按全字段直接展示（已定），但它在列表里不出现、只在详情出现，是否符合预期？

评审通过后，这些结论落进 `03-实现方案.md` 与真实页面；本 Demo 留在原处作为设计依据，不进产物代码。
