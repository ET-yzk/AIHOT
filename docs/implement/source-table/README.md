## 与既有功能的关系（别再问一遍）

- 与「法规追踪」（/regulations）**并存**：一个是动态资讯流，一个是台账。
- 与 `FEISHU_BITABLE_*` 环境变量**无关**：那是门户 → 飞书的出站投影（只写），本需求是飞书 → 门户的入站同步（只读），方向相反。
- 与 `/admin/sources`（采集信源管理）**无关**：同名不同物，那张表是 RSS/网页等采集源，这张是法规台账。
