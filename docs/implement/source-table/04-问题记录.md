## 5 记录在案但决定不做（避免以后重问）

| 项 | 决定 | 理由 |
|---|---|---|
| 站内编辑 / 新增法规 | 不做 | 权威在飞书，双写必不一致 |
| 与「法规追踪」合并 | 不合并 | 一个是动态资讯流，一个是台账，读者目的不同 |
| 复用 `FEISHU_BITABLE_*` 环境变量 | 不复用 | 那三个是**门户 → 飞书**的投影（只写），本需求是**飞书 → 门户**（只读），方向相反；混用会让两个功能互相牵制 |
| 开写权限 `bitable:app` | 不开 | 本需求只读；开写权限会让人误以为站点能改表 |
| 按角色的字段遮蔽 | 本期不做 | 站点没有角色体系（FR-09-07 未排期）；且使用者已定「全字段直接展示」 |
