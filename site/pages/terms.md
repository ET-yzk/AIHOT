页首说明：

> RegWatch 是公开信息的摘要与阅读索引：盯住国内外道路机动车领域的法规、标准、测评规程与行业动态，用模型生成中文标题、摘要和推荐理由，再把同一件事的多篇报道归到一起。原文版权归各来源所有。网页、RSS、公开 API 与 MCP 均可匿名使用，不需要注册。

## 1. 内容与版权

站内展示的标题、中文摘要、推荐理由、分类与标签都由模型根据公开来源生成，可能有误或滞后，重要信息请以原文为准——尤其是法规与标准文本，请以发布机关公布的正式文本为准。

原文版权归各来源所有。站内默认只展示摘要和原文链接，只有在来源明确允许的情况下才展示全文或全文 RSS；你不满意的展示方式可以告诉我们调整。

## 2. 来源方的更正与下架

如果你是发布机关、测评机构、车企或媒体，希望更正某条的展示方式、下架某条、或调整是否展示全文，请通过反馈页告诉我们（写下页面地址或标题即可），我们会尽快处理。下架只影响站内的展示，不影响公开来源本身。

## 3. 使用本站的数据

个人阅读、学习、研究，以及组织内部使用，可以直接用，不必打招呼。

对外产品或服务、公开转载、批量抓取与再分发，请先通过反馈页联系并取得同意。引用本站内容时请注明出处，并尽量同时给出原文的链接——本站的摘要不是各项事实的第一现场。

## 4. 接口与频率

三个公开出口都是匿名只读、无需密钥：RSS（全站、各分类、各报告）、公开 API `/api/v1/…`、MCP 工具（工具名以 `regwatch_` 开头）；另有 `llms.txt`、`/openapi-v1.json` 和给 Agent 的使用说明（`/api/v1/agent`）。

请按响应里的 `Cache-Control` 来决定多久取一次，不要并发重试，也不要用脚本高频轮询。日报每天 08:00（北京时间）出一份，绝大多数页面一天更新一次就够。本站在应用层对反馈提交和内容推送接口限流（超限会返回 429 并带 `Retry-After`）；公开读接口按现部署不在应用层按 IP 限流，若你收到 429，请同样按 `Retry-After` 等待后再来。

## 5. 免责

本站按“现状”提供，不保证内容完整、准确和持续可用。

本站对法规和标准的表述是模型生成的摘要，**不构成法律意见、合规建议或认证结论**；判断某项要求是否适用于你的产品，请以发布机关的正式文本和其官方解释为准。
